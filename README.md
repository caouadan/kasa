# Kasa – Application web de location immobilière

Kasa est une plateforme de location d’appartements entre particuliers en France.

Ce projet consiste à développer le front-end complet de l’application avec React, en s’appuyant sur des maquettes Figma et des données simulées issues d’un fichier JSON.

---

## Objectifs du projet

- Initialiser une application avec Vite
- Développer une interface avec React
- Créer des composants réutilisables
- Configurer la navigation avec React Router
- Implémenter des animations CSS
- Structurer le style avec Sass

---

## Technologies utilisées

- React
- React Router
- JavaScript
- HTML5
- CSS3 / Sass
- Vite
- Node.js
- Git / GitHub

---

## Fonctionnalités principales

- Affichage des logements à partir de données JSON
- Navigation entre les pages (Accueil, Logement, À propos)
- Galerie d’images avec navigation (suivant / précédent)
- Composants Collapse interactifs
- Gestion des cas particuliers (ex : une seule image)
- Interface responsive

---

## Architecture React

L’application est construite autour de composants réutilisables :

- Composants UI (cards, gallery, collapse)
- Pages (Home, Logement, About, Error)
- Gestion des props pour transmettre les données
- Séparation claire entre logique et présentation

---

## Navigation avec React Router

Le routage permet de gérer les différentes صفحات de l’application :

- Navigation sans rechargement de page
- Routes dynamiques pour les logements
- Gestion des erreurs (page 404)

---

## Gestion des données

Les données sont simulées via un fichier JSON :

- Récupération et affichage des logements
- Injection dynamique dans les composants
- Gestion des états d’affichage

---

## Animations et styles

- Animations CSS pour les composants Collapse
- Mise en page responsive
- Organisation des styles avec Sass
